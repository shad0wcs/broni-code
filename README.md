## Информация о боте

Бот следит за чатом в **Пачке**, находит уведомления о новых и просроченных бронированиях и пересылает их в чат команды магазина.

Использование бота позволило повысить процент вовремя собранных заказов.

## Как работает

1. Каждые 15 секунд бот смотрит в чат Пачки и читает последние 20 сообщений.
2. Каждое сообщение обрабатывается только один раз.
3. Бот ищет в чате ключевые фразы:
    - **новые заказы** -> собирает номера заказов, время и магазин и отправляет уведомление в чат команды
    - **просроченные заказы** -> отправляет срочное уведомление с количеством минут просрочки
4. Если возникают ошибки - бот пробует еще раз, до трёх попыток.

> При запуске бот запоминает все сообщения, которые уже есть в чате, и уведомляет только о новых. Поэтому заказы, пришедшие, пока бот был выключен или перезапускался, в Telegram не попадут.

```
🏪 Город | Название магазина
 
  📦 Номер заказа 🕒 Время
 
⏰ Соберите за 30 минут!
```

```
🚨 ПРОСРОЧЕННЫЕ ЗАКАЗЫ!
🏪 Название магазина

  📦 Номер заказа 🕒 Время

⌛️ Просрочено: 54 мин
📊 Итого: 1 заказ в 1 магазине
❗️ Срочно свяжитесь с сотрудниками!
```
